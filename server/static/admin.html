Название Автор Отдел Вопросы Таймер

У каждого теста свой список курсантов (позывной, номер, ФИО) — вручную или из Excel. Один раз; повтор — пароль пересдачи. Свой тест можно полностью отредактировать (кнопка «Редактировать» или клик по строке) — в том числе пополнить банк вопросов из другого файла; ссылка не изменится.

Одна шкала на все тесты. Процент = верные ответы / все вопросы. Вопрос без ответа считается неверным. Блок «Из отвеченных» оценку не меняет. Ручную оценку администратора и старшего инструктора шкала не затирает.
