# Архив: старый генератор тестов

Снят с публичного доступа. Создание и работа с тестами — только через кабинет преподавателя (мастер во вкладке «Тестирование»).

Файлы здесь — снимок прежнего standalone UI (вкладки Банк / Параметры / Оценка) для истории. Не подключать из роутинга и не давать прямых ссылок.

Рабочий движок мастера по-прежнему обслуживается из `Генератор_тестов.html` + `/static/generator/*`, но только с параметрами `cabinet=1&wizard=1`.
